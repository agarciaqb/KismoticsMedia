# Política de Privacidad **Fecha de entrada en vigor:** [30/07/2016] **Última actualización:** [30/08/2026] Esta Política de Privacidad explica cómo KismoticsMEDIA (“la Aplicación”, “nosotros” o “nuestro”) recopila, utiliza, conserva y protege la información de las personas que utilizan nuestra aplicación o servicios relacionados. ## 1. Responsable del tratamiento El responsable del tratamiento de los datos es: - **Nombre / titular:** KismoticsMedia - **Correo electrónico de contacto:** kismotics@gmail.com - **País de residencia:** España - **Dirección de contacto, si corresponde:** “No aplicable” ## 2. Información que podemos recopilar Dependiendo de las funciones utilizadas, la Aplicación puede recopilar o recibir las siguientes categorías de datos: - Identificadores básicos de la cuenta, como nombre, identificador de usuario o foto de perfil, cuando el usuario autoriza el acceso mediante Facebook Login u otro proveedor de autenticación. - Dirección de correo electrónico, cuando el usuario la facilita o autoriza expresamente. - Información técnica, como dirección IP, tipo de navegador, sistema operativo, idioma, registros de errores y datos necesarios para garantizar la seguridad y el funcionamiento técnico del servicio. - Contenido que el usuario proporciona voluntariamente a la Aplicación, por ejemplo textos, imágenes, archivos, instrucciones o configuraciones. - Tokens de acceso o credenciales técnicas proporcionadas por plataformas externas, cuando sean necesarios para prestar una función autorizada por el usuario. No solicitamos ni tratamos deliberadamente categorías especiales de datos personales, salvo que el usuario las proporcione voluntariamente y sean estrictamente necesarias para la función solicitada. ## 3. Finalidades del tratamiento Podemos utilizar la información recopilada para: - Proporcionar, operar y mantener las funciones de la Aplicación. - Identificar o autenticar al usuario cuando utilice un inicio de sesión de terceros. - Ejecutar las acciones expresamente solicitadas por el usuario. - Mejorar el rendimiento, la seguridad y la estabilidad de la Aplicación. - Diagnosticar errores, prevenir usos fraudulentos o abusivos y proteger el servicio. - Comunicarnos con el usuario cuando sea necesario para responder a una consulta o incidencia. - Cumplir obligaciones legales aplicables. No vendemos los datos personales de los usuarios. ## 4. Base jurídica Cuando resulte aplicable conforme al Reglamento General de Protección de Datos (RGPD), tratamos los datos personales sobre las siguientes bases: - El consentimiento del usuario, cuando autoriza el acceso a información o utiliza voluntariamente una función. - La ejecución de una solicitud o servicio solicitado por el usuario. - El interés legítimo en mantener la seguridad, prevenir fraudes y mejorar el funcionamiento de la Aplicación. - El cumplimiento de obligaciones legales, cuando sea necesario. El usuario puede retirar su consentimiento en cualquier momento, sin que ello afecte a la licitud del tratamiento realizado antes de su retirada. ## 5. Datos recibidos de Meta/Facebook Si el usuario decide conectar su cuenta de Facebook o utilizar funciones de Meta, la Aplicación solo solicitará los permisos y datos estrictamente necesarios para la función correspondiente. Los datos recibidos de Meta/Facebook se utilizarán únicamente para prestar la funcionalidad que el usuario haya autorizado. No utilizaremos dichos datos para fines incompatibles con dicha autorización ni los venderemos a terceros. El usuario puede revocar el acceso de la Aplicación desde la configuración de aplicaciones y sitios web de su cuenta de Facebook o Meta. ## 6. Compartición de información No compartimos datos personales con terceros salvo en los siguientes casos: - Cuando sea necesario para prestar el servicio solicitado por el usuario. - Con proveedores técnicos que alojan o procesan datos por nuestra cuenta, bajo obligaciones de confidencialidad y seguridad. - Cuando exista una obligación legal, requerimiento de una autoridad competente o sea necesario para proteger derechos, seguridad o integridad del servicio. - Cuando el usuario haya dado su consentimiento explícito. Si utilizamos servicios de terceros, como alojamiento web, analítica, almacenamiento, APIs de inteligencia artificial o servicios de autenticación, estos proveedores podrán tratar datos únicamente en la medida necesaria para prestar sus servicios. ## 7. Conservación de los datos Conservamos los datos personales solo durante el tiempo necesario para cumplir las finalidades descritas en esta política, atender obligaciones legales, resolver incidencias o proteger la seguridad de la Aplicación. Cuando los datos ya no sean necesarios, se eliminarán o anonimizarán de forma razonable y segura. ## 8. Seguridad Adoptamos medidas técnicas y organizativas razonables para proteger la información frente a acceso no autorizado, pérdida, alteración, divulgación o destrucción. Sin embargo, ningún sistema de transmisión o almacenamiento electrónico puede garantizar una seguridad absoluta. El usuario debe proteger sus credenciales y no compartir datos confidenciales innecesariamente. ## 9. Derechos de los usuarios De acuerdo con la normativa aplicable, el usuario puede solicitar: - Acceso a sus datos personales. - Rectificación de datos inexactos o incompletos. - Supresión de sus datos. - Limitación del tratamiento. - Oposición al tratamiento cuando corresponda. - Portabilidad de los datos, cuando sea aplicable. - Retirada del consentimiento en cualquier momento. Para ejercer estos derechos, puede escribir a: **[TU_EMAIL@EJEMPLO.COM]** También puede presentar una reclamación ante la autoridad de protección de datos competente. En España, esta autoridad es la Agencia Española de Protección de Datos (AEPD). ## 10. Eliminación de datos Los usuarios pueden solicitar la eliminación de los datos asociados a su cuenta o a su uso de la Aplicación enviando una solicitud a: **[TU_EMAIL@EJEMPLO.COM]** Incluya, si es posible, el nombre de usuario, correo electrónico o identificador asociado a la cuenta para que podamos localizar los datos correspondientes. Procesaremos las solicitudes de eliminación en un plazo razonable, salvo que debamos conservar determinada información para cumplir obligaciones legales, resolver disputas, prevenir fraude o proteger la seguridad del servicio. ## 11.
